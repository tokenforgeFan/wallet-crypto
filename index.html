Synchro avec maj.py

À chaque exécution, maj.py dépose un export dans ton dépôt GitHub privé. L'appli le récupère toute seule à l'ouverture et toutes les 3 minutes. Utilise ici un jeton en lecture seule sur ce seul dépôt, différent de celui du PC.

Les données restent sur cette tablette (stockage local du navigateur). Rien n'est envoyé ailleurs : seule la liste des identifiants CoinGecko part vers l'API pour obtenir les prix, et la synchro ne fait que lire ton dépôt GitHub privé. Prix : CoinGecko, actualisés toutes les 3 minutes quand l'appli est ouverte.
